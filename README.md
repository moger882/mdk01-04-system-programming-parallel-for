# Вариант 7 — статистика массива с Parallel.For

Выполнил: Жиличкин Сергей, группа 32.

## Задание

Создать массив из 100 000 целых чисел. Вычислить минимум, максимум, сумму и среднее двумя способами:

1. обычным циклом `for`;
2. параллельным циклом `Parallel.For`.

Сравнить время выполнения и убедиться, что результаты совпадают.

## Запуск

Требуется .NET 8 SDK или новее.

```bash
dotnet run -c Release
```

Программа использует фиксированный `seed`, поэтому оба алгоритма каждый раз обрабатывают одинаковый массив. Перед измерением выполняется прогрев методов, чтобы первая JIT-компиляция меньше влияла на сравнение.

## Как работает программа

- `CreateArray` создаёт 100 000 чисел от -10 000 до 10 000.
- `CalculateSequential` последовательно обходит массив и собирает статистику.
- `CalculateParallel` использует локальную статистику для каждой рабочей задачи `Parallel.For`. Локальные результаты объединяются в общей секции под `lock`, поэтому гонки данных нет.
- `Measure` измеряет время через `Stopwatch`.
- После расчётов программа сравнивает все значения. При расхождении завершение происходит с кодом `1`.

На таком небольшом массиве параллельный вариант может оказаться медленнее: создание и планирование параллельной работы, а также объединение результатов имеют накладные расходы. Это нормальный результат измерения, а не ошибка.

## Ответы на контрольные вопросы

### 1. Когда удобны именованные каналы

Именованные каналы удобны для обмена данными между независимыми процессами на одном компьютере или в локальной сети. У канала есть имя, по которому клиент подключается к серверу. Это подходит для клиент-серверного взаимодействия, передачи команд и небольших сообщений без создания временных файлов. В .NET для этого применяются `NamedPipeServerStream` и `NamedPipeClientStream`.

### 2. Чем File отличается от Directory в .NET

`File` содержит статические методы для работы с файлами: создание, чтение, запись, копирование, перемещение и удаление. `Directory` содержит методы для работы с каталогами: создание и удаление папок, получение списка файлов и подкаталогов, перемещение каталогов. Для объектного представления с состоянием используются классы `FileInfo` и `DirectoryInfo`.

### 3. Зачем нужен CancellationToken

`CancellationToken` позволяет корректно и совместно отменять длительную операцию. Код периодически проверяет `IsCancellationRequested` или вызывает `ThrowIfCancellationRequested`, после чего освобождает ресурсы и завершает работу в контролируемом состоянии. Токен не завершает поток принудительно: операция должна сама поддерживать отмену.
